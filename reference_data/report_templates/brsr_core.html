Appendix B. Methodology

  • Framework: GHG Protocol Corporate Standard (WRI & WBCSD).
  • Scope 2 accounting: Location-based, using the CEA all-India grid emission factor ({{ grid_factor | default("0.7117 tCO₂/MWh, FY24-25") }}).
  • Global warming potentials: IPCC AR6 100-year values.
  • Emission factor sources: CEA CO2 Baseline Database v20.0, IPCC AR6, India GHG Program, DEFRA GHG Reporting 2024, PPAC coal calorific values.
  • Reference data version: {{ run.ef_version }}.
  • Recommendation engine: Retrieval-augmented reasoning over a curated intervention library sourced from BEE Technology Bank, TERI sector reports and CII manuals. Emission and cost calculations are deterministic; no ML predictions are used in the primary numbers.
